# Council analyses: numbers the manuscript may cite

Generated by `_tools/council_analyses.py`; verified by `_tools/verify_council_analyses.py` (see `verification.csv`). Do not edit by hand; rerun the scripts.

- Data: `EndlessRay/asha-benchmarks@09df556e0ad5`, the commit the paper cites; Hard ids `hb_hard.jsonl` sha256/16 `b0320430e5cd974e` (1,000 ids).
- Python 3.12.13, NumPy 1.26.4, SciPy 1.16.3. Seed 20261016; B = 10,000 item resamples for CIs, 20,000 for harm CIs and bootstrap P.
- Points are percentage points of the HealthBench rubric score (item score x 100). Arms: Asha = `asha-apex-j-frozen`, bare = `bare-gpt-6-astra`.

## Methods

- **Item score**: `score` field = sum of points of met criteria / sum of positive points, unclipped (items can be negative). The verification script recomputes it from criteria.
- **Failed grade**: a criterion whose explanation starts with `Parse failed` (no verdict) or `Backup parse` (verdict recovered by a fallback parser). Only Claude Opus 4.8 grades contain them.
- **Pairing rule (primary, `readout`)**: an item is dropped from both arms for a grader if either arm's grade of that item contains a failed criterion. This is the rule the official readouts used; it reproduces their n and differences exactly. Sensitivity rules: `criterion` (keep all items, drop `Parse failed` criteria from both arms, rescore) and `all` (keep every stored verdict; the rule of `_tools/harm_ci.py`). GPT graders are unaffected by the rule.
- **Bootstrap**: paired item-level percentile bootstrap (items resampled, both arms together). Bootstrap P two-sided, with +1 correction (floor 2/(B+1) = 1.0e-4 at B = 20,000).
- **Harm estimators** (items with at least one negative criterion): criterion-pooled ratio (paper's), item-mean of per-item rates, item-level any-harm (share of items with at least one negative criterion met), severity-weighted (negative points met per item). Holm and Bonferroni across the six grader-by-set contrasts, within each estimator.
- **Severe**: negative criterion with points <= -9. An item is Asha-only severe if Asha meets a severe criterion bare does not and bare meets none that Asha does not; unanimous = all three graders classify the item that way (items valid for all three). Exact two-sided binomial test on discordant items.
- **Length**: characters of the final assistant message in `completions.jsonl.gz`; ratio = Asha / bare; tertiles cut on the log ratio within each set (grader-invariant). Length-controlled gain = intercept of OLS of per-item gain on log length ratio (gain at equal length), CI by item bootstrap, HC3 interval reported alongside.
- **Agreement**: Cohen kappa on criterion `met`, pooled over items, criteria matched by position, failed grades excluded pairwise.
